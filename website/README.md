# Pweza Beach Resort — Website

A static, dependency-free site. Open `index.html` in a browser, or serve the folder:

    cd website && python3 -m http.server 8080

Files:
- `index.html` — page content and structure
- `styles.css` — design system and responsive layout
- `assets/hero.jpg` — AI-generated placeholder hero image; swap for real resort photography when available

Before launch, replace placeholder imagery with real photos and confirm the name (one review refers to the property as "Villa Dahl Beach Resort").
